# 기록판 서버 설치 (한 번만)

게임 전용 구글 계정(**staffsmash0**)으로 로그인한 브라우저에서 진행한다. 국제교류팀 공식 계정으로 만들지 않는다.

1. https://sheets.new 에서 새 스프레드시트를 만들고 이름을 `Staff Smash 기록판`으로 바꾼다.
2. 메뉴 **확장 프로그램 → Apps Script**를 연다.
3. 기본 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs`를 통째로 붙여 넣고 저장한다.
4. 오른쪽 위 **배포 → 새 배포**를 누른다.
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나(staffsmash0)**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르고 권한 승인 화면에서 staffsmash0 계정으로 허용한다. ("확인되지 않은 앱" 경고가 나오면 고급 → 이동)
6. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사한다.
7. 게임 레포의 `src/data/server.json`의 `recordsUrl`에 그 주소를 넣고 커밋하면 배포된다.

## 운영

- 기록은 시트의 `records` 탭에 한 줄씩 쌓인다. 닉네임이 빈 줄은 익명 플레이(순위에는 안 나옴)다.
- `mode` 칸: `staff`·`student`는 본편(2D), `fps-staff`·`fps-student`는 1인칭 시험판 기록이다. 기록판은 모드별로 따로 순위를 매긴다.
- 12번째 칸(L열) `diff`는 1인칭 난이도(`easy` 초보 · `normal` 중급 · `hard` 고급)다. 2D 기록은 비어 있다. 예전 시트는 새 `Code.gs`가 처음 불릴 때 L1에 `diff` 머리글을 알아서 붙인다.
- 부적절한 닉네임이나 조작된 기록은 그 행을 지우면 끝이다.

### Code.gs를 바꿨을 때 (다시 배포)

1. staffsmash0 계정으로 시트의 **확장 프로그램 → Apps Script**를 연다.
2. `Code.gs` 내용을 이 폴더의 `Code.gs`로 통째로 바꾸고 저장한다.
3. 오른쪽 위 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 누른다.
   - **새 배포**가 아니라 기존 배포를 **수정**해야 웹 앱 URL이 그대로다. `src/data/server.json`은 바꾸지 않는다.
4. 그러면 끝이다. **1인칭 기록판은 이 배포가 끝나면 저절로 열린다** (게임 쪽 코드는 따로 고칠 필요 없음).
   - 1인칭 게임은 서버에 `?mode=fps-staff`로 물어보고, 답의 `mode`가 `fps-staff`일 때만 온라인으로 올린다. 예전 서버는 `staff`라고 답하므로 그동안은 기록을 그 기기에만 저장한다(2D 기록판이 섞이지 않는다).
   - 확인: 브라우저에서 `웹 앱 URL?mode=fps-staff`를 열어 `"mode":"fps-staff"`가 보이면 새 버전이다.
