# Three Party Problem

교직원과 학생이 서로의 입장을 웃으면서 겪어 보는 2D 벨트스크롤 액션 게임. 프레지던트 캉을 제외한 인물과 부서는 가상이다. 장소는 한국외대 서울캠퍼스의 실제 건물이다.

게임 이름은 2026-11-20 "Staff Smash: HUFS"에서 "Three Party Problem"으로 바뀌었다. 저장소·주소·저장 키(`staffsmash.*`)는 staff-smash 그대로다.

플레이: https://staffsmash.github.io/staff-smash/

1인칭 시험판(별도 페이지): https://staffsmash.github.io/staff-smash/fps.html

현재 단계: **M3 — 학생 모드 추가**. 타이틀에서 모드를 고른다.

- **교직원 모드 (출근하기)**: 오후 4시 52분, 퇴근(17:00) 8분 전. 본관 민원 창구에서 대운동장까지 밀려드는 민원을 처리하고 정시 퇴근을 노린다.
- **학생 모드 (등교하기)**: 같은 오후 4시 52분, 반려된 졸업 서류를 들고 대운동장에서 본관 총장실까지 올라가 본관 업무 마감(17:00) 전에 프레지던트 캉의 "승인"을 받는다. 엔딩은 꿈이었고, 오늘은 수강신청 날이다.

게임 속 시계는 실제 시간과 같이 흐르므로 세 스테이지를 8분 안에 끝내면 정시 퇴근(승인)이다. 기록판은 두 모드 모두 끝낸 시각으로 순위를 매기고, 학생 모드는 GPA를 함께 보여 준다.

## 교직원 모드 구성

| 스테이지 | 구역 | 중간보스 | 보스 | 방해 상사 |
|---|---|---|---|---|
| 1. 본관 → 사회과학관 | 본관 민원 창구 → 본관 로비 → 본관 앞 → 사회과학관 앞 | 전화번호 잘못 입력한 학생, 서류 제출이 늦은 학생 | 공지를 안 읽는 학생 (안내문 3번 붙이기) | 김보고 처장, 박학과장 (메일·전화 떠넘기기) |
| 2. 교수학습개발원 → 인문과학관 | 교수학습개발원 앞 → 교수학습개발원 로비 → 인문과학관 앞 → 인문과학관 강의실 앞 | 규정을 읽지 않고 떼쓰는 학생, 졸업시켜 달라는 학생 | 마감 1분 전에 오는 학생 (마감 시계) | 최내놔 처장 (거미줄 — 밟으면 처장 곁으로 끌려간다), 몰라몰라부총장, 김부재중 교수(서명 대기), 회의회의부총장 |
| 3. 국제학사 → 운동장 | 국제학사 앞 → 운동장 스탠드 → 운동장 트랙 → 대운동장 | 총장실로 메일 쓰는 학생, 단대학생회 간부 최민원 | 총학 집행부 3명 | 전원 |

- 잡몹: 새벽 3시 메일, 울리는 전화기, "교수님이 된다고 했는데요" 말풍선, 마감 1분 전 서류 뭉치, 단체 문의 줄
- 무기: 스테이플러, 안내문 롤, 결재판(정면 방어), 사원증(부메랑). 던지기 전용: 규정집, 서류 뭉치. 바닥에 놓여 있지 않고 **경비 선생님께 인사(L)하면** 받는다(경비 선생님을 치면 잠시 안 준다). 보스 기믹에 필요한 무기는 경비 선생님이 던져 준다. 경비 선생님은 구역마다 남녀가 번갈아 선다.
- 회복: 학식 돈가스, 삼각김밥, 아메리카노, 식권(체력 전부) — **조기출근 박스**를 깨면 나온다. 잡몹이 가끔 음식·보조배터리(필살기 +50)를 떨어뜨린다. 몰라몰라부총장이 주는 것 중 하나는 일거리
- 잡몹이 가끔(각 약 2.5%) 떨어뜨리는 것: **연차 쿠폰**(다음 한 번은 피해·밀림·느려짐 없이 막는다, 30초), **셔틀버스 시간표**(10초 동안 이동 속도 +30%), **단톡방 공지 캡처**(살아 있는 잡몹만 2.5초 멈춤 — 중간보스·보스·학생은 그대로). 상자에서는 나오지 않는다
- 같은 방식(잡몹이 약 2.5%로 떨어뜨림, 상자에서는 안 나옴)으로 얻는 **인감 도장**(학생 모드: **출석 스티커**): 8초 동안 맨손 공격(처리, J)이 잡몹을 넘어뜨린다. 중간보스·보스·학생은 넘어뜨리지 않는다
- 조력자: 체력이 25% 이하로 떨어지면 스테이지마다 한 번 60% 확률로 동료 직원들이 몰려와 잡몹을 처리하고 체력을 채워 준다("서류 마감기간이니 제가 대신 해드릴게요!", "○○○님! 전화 대신 받아드려요!")
- 주인공: 가상 행정직원 6명 중 선택 (능력 같음). 필살기: 업무 스킬 4종 중 선택
- 엔딩 후 닉네임으로 기록판에 기록 (건너뛰면 익명 1건)
- 학생 이름은 매 판 무작위로 바뀐다. 학생은 넘어지지 않고, 처리되면 인사하고 돌아간다.

## 학생 모드 구성

| 스테이지 | 구역 | 창구 직원 (중간보스) | 보스 |
|---|---|---|---|
| 1. 대운동장 → 국제학사 | 대운동장 → 운동장 트랙 → 운동장 스탠드 → 국제학사 앞 | 김전략(순위 하락 화살표), 최도서관(책수레) | 전필수 · 스페인어과 학과장 (수강편람 탑을 무너뜨려야 설득, "재수강" 도장) |
| 2. 인문과학관 → 교수학습개발원 | 인문과학관 앞 → 인문과학관 강의실 앞 → 교수학습개발원 로비 → 교수학습개발원 앞 | 나진취(첨삭 선), 김국제(여권 부채꼴) | 김부재중 교수 (자리를 자주 비우고, 정면으로 던진 것은 결재판으로 되받아친다) |
| 3. 사회과학관 → 본관 | 사회과학관 앞 → 본관 앞 → 본관 로비 → 본관 총장실 | 권학생(총학 면담 — 앞을 막는다), 김학종지(번호표 소환) | 관문: 한학고 · 영어대학 학장 (성적표 A+/F) → 프레지던트 캉 (거대 도장·MOU 서명·기념 촬영·학위 수여 → 수강신청 서버 폭주) |

- 주인공: 김러샤, 이엘LT, 박불어, 정헝가리 (능력 같음, 남녀 섞임). 등장 때 나라말로 인사한다. 맨손 3타: 잽 → 잽 → 가방 휘두르기
- 필살기: 외국어 주문 4종 — 영어 DEADLINE EXTENDED! (마감 연장!), 스페인어 ¡Olé! (좋아!), 러시아어 ЗАЧЁТ! (통과!), 아랍어 يلا! (가자!)
- 잡몹: 반려 서류, 결석 도장, 휴강 공지 봇, 마감 시계, 대기번호표 (교직원 잡몹과 움직임이 같고 겉모습만 다르다)
- 무기: 텀블러, 장우산, 전공책(정면 방어), 학생증(부메랑). 던지기 전용: 마감 시계. **도서 무인 대출기**에서 대여(L)하면 나온다
- 잡몹이 가끔 떨어뜨리는 것: **공결 확인서**(교직원 모드의 연차 쿠폰), 셔틀버스 시간표, 단톡방 공지 캡처, **출석 스티커**(교직원 모드의 인감 도장) (효과는 교직원 모드와 같다. 창구 직원·보스는 멈추지 않는다)
- 회복: **수강편람**을 깨면 식권이나 음식이 나온다. 조력자는 친구들("○○○아! 내가 대신 서류내줄게", "○○○아, 도와줄게!" — 받침에 따라 아/야)
- 스테이지마다 성적표(A+~F), 끝나면 최종 GPA(4.5 만점). 창구 직원과 보스는 쓰러지지 않는다. 창구 직원은 설득되면 "퇴근합니다…" 하며 물러나고, 학과장·학장은 "승인 완료!", 교수는 "서명 완료!"로 끝난다.

## 캠퍼스 배경과 학교 로고

- 배경은 서울캠퍼스 실제 건물(본관, 사회과학관, 교수학습개발원, 인문과학관, 국제학사, 대운동장)을 학교 캠퍼스맵과 홍보 사진을 보고 코드로 그린 블록 도형이다(`src/scenes/background.ts`). 사진 파일은 레포에 넣지 않는다.
- 국제학사는 캠퍼스맵의 '학생회관 및 기숙사'(4번) 건물, 영문 GlobeeDorm이다. 인문관은 공식 이름 '인문과학관'으로 쓴다.
- 학교 로고는 새 학교 UI(남색 단색 심벌 + 굵은 고딕 HUFS)를 `public/hufs/`에 두고 쓴다(`src/hufs.ts`). 남색 심벌(`emblem.png`), 흰색 심벌(`emblem-mono.png`), 영문 약칭 HUFS(`hufs-type.png`), 국문 로고타입(`wordmark-ko.svg`). 흰색 파일은 게임에서 흰색·금색·남색을 입힌다. 모양과 비율은 바꾸지 않는다. 원본은 팀 드라이브 `2 협정\2 HUFS UI\추가_UI\`.

## 1인칭 시험판

`fps.html` + `src/fps/` (Three.js). 1인칭으로 본관 앞 → 사회과학관 앞 → 인문과학관 앞 → 국제학사 앞 → 대운동장 → 해 질 녘 본관 앞을 돌며 메일·전화기·말풍선·서류 뭉치(잡몹은 모두 물건)에 도장을 던져 처리하고, 다섯 구역마다 중간보스(2D 민원 학생)를 먼저 처리한 뒤 사람 보스에게 결재를 받는다.

| 구역 | 중간보스 (2D 민원 학생) | 보스 |
|---|---|---|
| 1. 본관 앞 | 전화번호 잘못 입력한 학생 — 사라졌다가 다른 자리에 나타난다 | 김총괄 (교직원·대관 담당) |
| 2. 사회과학관 앞 | 공지를 안 읽는 학생 — 질문 서류를 줄지어 던지고, 막대가 ⅓ 찰 때마다 안내문이 붙어 "…읽는 중" | 김보고 처장 |
| 3. 인문과학관 앞 | 마감 1분 전에 오는 학생 — 마감 시계 60초(넘기면 진행이 되돌아가고 초과근무 2분), 돌진·서류 뭉치 | 박학과장 — "그건 선생님이 알아서 하세요" 하며 메일·전화를 떠넘긴다 (막대: 협조 서명) |
| 4. 국제학사 앞 | 단대학생회 간부 최민원 — 서명지를 흔들면 민원이 몰려온다. 들어 올린 서류를 맞혀 서명지를 떨어뜨리고 먼저 주우면 그친다 | 최내놔 처장 — "손님이 오는데 기념품 없나요?" 하며 거미줄을 던진다. 밟으면 처장 곁으로 끌려간다 |
| 5. 대운동장 (동쪽 철망 문으로 들어간다) | 총장실로 메일 쓰는 학생 — 메일을 다 쓰면 "지시" 서류 셋이 떨어진다. 쓰는 중에 맞히면 멈춘다 | 회의회의부총장 |
| 6. 해 질 녘 본관 앞 | — | 총장 프레지던트 캉 — 거대 도장, MOU 서명선, 기념 촬영(마주 보면 화면이 하얘진다), 표창장 부메랑 |

사람(중간보스·보스)은 다치지 않는다 — 도장은 들고 있는 서류·결재판에 찍히고 "처리"(학생)·"결재 진행"(보스)이 차면 2D 마무리 대사를 하고 걸어 나가며, 총장은 선 채로 "퇴근 승인"·"월급 인상" 도장을 찍어 준다(홍보실·비서실 확인, 2026-11-13). 민원 학생 이름은 2D처럼 판마다 무작위로 붙는다(최민원은 고정). 새 구역 두 곳(`src/fps/campus.ts`)은 2D 배경의 인문과학관(띠창·떠 있는 지붕·석등·지구 모양 기념탑)과 국제학사(학생회관 및 기숙사)를 블록으로 옮긴 것이고, 사회과학관 뒤 → 대운동장 동쪽으로 이어진다. 중간보스·새 보스는 `src/fps/mids.ts`. 난이도 초보(기본)·중급·고급, 점프, 음식, 필살기(교직원 4종, 아래 7차), 설정, 난이도별 최고 기록, 근무평정 결과가 있다. 2D와 같은 조력자 이벤트, 경비 선생님 인사(E)·도서 무인 대출기(E)로 받는 무기 4종(횟수 제한 — 연사·관통·묵직한 한 방·부메랑), 조기출근 박스·수강편람에서 나오는 식권·음식, 보조배터리, 민원이 가끔 떨어뜨리는 연차 쿠폰(학생: 공결 확인서)·셔틀버스 시간표·단톡방 공지 캡처(2D와 효과가 같다, 체력이 4 이하일 때는 음식이 먼저)가 있다. 결과 화면에서 닉네임으로 **1인칭 전용 기록판**(`src/fps/board.ts`, 서버 모드 `fps-staff`·`fps-student`, 난이도 열)에 남긴다 — 서버를 새 Code.gs로 다시 배포하기 전에는 이 기기에만 저장한다.

- 식권 → 자판기(교직원, `src/fps/vending.ts`): 조기출근 박스는 늘 식권 1장 → HUD "식권 N장"(바로 회복 없음). 구역마다 남색 자판기 앞에서 E(터치 "넣기")로 한 장 넣으면 무작위 아이템(음식·아메리카노·보조배터리·연차 쿠폰·셔틀버스 시간표·단톡방 공지 캡처·인감 도장, 무기 없음, 체력이 낮을수록 음식, 가끔 체력을 모두 채우는 "학식 치킨돈가스"). 학생 모드 수강편람·식권은 그대로. 시험: `__fps.vend.tickets`, `__fps.vend.use()`.

## 기록판 서버

`apps-script/` 폴더의 `Code.gs`를 게임 전용 계정(staffsmash0)의 Google 시트에 붙여 웹 앱으로 배포했고, 주소가 `src/data/server.json`의 `recordsUrl`에 들어 있다. 설치 순서는 `apps-script/README.md`. 주소를 비우면 기록은 각 기기에만 저장된다. 1인칭 기록판(`fps-staff`·`fps-student`)은 새 `Code.gs`를 다시 배포해야 열린다(배포 → 배포 관리 → 수정 → 새 버전, 주소는 그대로). 그 전에는 게임이 서버 응답의 `mode`를 보고 1인칭 기록을 보내지 않는다. 2026-11-15부터 1인칭 구역은 6개(`MODE_MAX` 6)다. 2026-11-17 사용자가 최신 `Code.gs`를 처음 쓰던 프로젝트(2D 기록이 있는 시트)에 붙여 새로 배포했고, `server.json`을 그 주소로 바꿨다. 11-14에 따로 만든 프로젝트·시트(1인칭 기록 1건)는 더 쓰지 않는다.

## 홈 화면 앱

휴대폰에서 2D·1인칭 어느 주소로든 "홈 화면에 추가"하면 같은 앱 "Three Party"가 된다(`public/manifest.webmanifest`, 시작 화면 `app.html` — [2D 게임]·[1인칭 게임]). 주소창 없이 전체 화면·가로로 열리고, 앱일 때만 두 타이틀에 "처음으로"가 보인다. 휴대폰 브라우저로 열면 타이틀 아래에 설치 안내 한 줄(닫으면 다시 안 뜸, `src/pwa.ts`). 아이콘은 `assets/icons/make_icons.py`로 다시 굽는다. service worker·오프라인 실행은 없다(늘 최신).

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 확인
```

- 엔진: Phaser 3 + TypeScript, 빌드: Vite
- 밸런스: `src/data/enemies.json`(적), `weapons.json`(무기), `stage1~3.json`·`student1~3.json`(구역·웨이브·상사·경비 선생님/대출기 `givers`·상자 `boxes`)
- 주인공·스킬: `src/data/heroes.ts`, `skills.ts`
- `main` 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages로 배포한다.
- 자동 시험: `?debug&timer` — `window.__game`이 열리고, 창이 가려져도 게임 루프가 돈다.
- 프레지던트 캉은 총장실이 준 사진을 보고 블록형으로 옮긴 외형이다(`src/entities/rigs.ts`의 `createPresidentRig`, `createPresidentPortrait`). 원본 사진은 레포에 넣지 않는다(`.gitignore`의 `president.*`).
- 에셋 출처는 `assets/CREDITS.md`에 기록한다.
