# Staff Smash: HUFS (비공식)

교직원과 학생이 서로의 입장을 웃으면서 겪어 보는 2D 벨트스크롤 액션 게임. 비공식 게임이며, 프레지던트 캉을 제외한 인물과 부서는 가상이다. 장소는 한국외대 서울캠퍼스의 실제 건물이다.

플레이: https://staffsmash.github.io/staff-smash/

1인칭 시험판(본관 앞, 별도 페이지): https://staffsmash.github.io/staff-smash/fps.html

현재 단계: **M2 — 교직원 모드 완성** (+ 캠퍼스 실제 건물 배경, 온라인 기록판). 오후 4시 52분, 퇴근(17:00) 8분 전. 본관 민원 창구에서 대운동장까지 밀려드는 민원을 처리하고 정시 퇴근을 노린다. 게임 속 시계는 실제 시간과 같이 흐르므로 세 스테이지를 8분 안에 끝내면 정시 퇴근이다.

## 구성

| 스테이지 | 구역 | 중간보스 | 보스 | 방해 상사 |
|---|---|---|---|---|
| 1. 본관 → 사회과학관 | 본관 민원 창구 → 본관 로비 → 본관 앞 → 사회과학관 앞 | 전화번호 잘못 입력한 학생, 서류 제출이 늦은 학생 | 공지를 안 읽는 학생 (안내문 3번 붙이기) | 김보고, 오검토 |
| 2. 교수학습개발원 → 인문과학관 | 교수학습개발원 앞 → 교수학습개발원 로비 → 인문과학관 앞 → 인문과학관 강의실 앞 | 규정을 읽지 않고 떼쓰는 학생, 졸업시켜 달라는 학생 | 마감 1분 전에 오는 학생 (마감 시계) | 최몰라, 허허실실, 김부재중(결재 대기), 회의소집 |
| 3. 국제학사 → 운동장 | 국제학사 앞 → 운동장 스탠드 → 운동장 트랙 → 대운동장 | 총장실로 메일 쓰는 학생, 단대학생회 간부 최민원 | 총학 집행부 3명 | 전원 |

- 잡몹: 새벽 3시 메일, 울리는 전화기, "교수님이 된다고 했는데요" 말풍선, 마감 1분 전 서류 뭉치, 단체 문의 줄
- 무기: 스테이플러, 안내문 롤, 결재판(정면 방어), 사원증(부메랑). 던지기 전용: 규정집, 서류 뭉치
- 회복: 학식 돈가스, 삼각김밥, 아메리카노 (허허실실 부총장이 주는 것 중 하나는 일거리)
- 주인공: 가상 행정직원 6명 중 선택 (능력 같음). 필살기: 업무 스킬 4종 중 선택
- 엔딩 후 닉네임으로 기록판에 기록 (건너뛰면 익명 1건)
- 학생 이름은 매 판 무작위로 바뀐다. 학생은 넘어지지 않고, 처리되면 인사하고 돌아간다.

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 (깊이축 포함) | 방향키 / WASD | 왼쪽 화면 드래그 |
| 대시 | 같은 방향 두 번 | 조이스틱 끝까지 밀기 |
| 처리(공격) · 매달린 학생 떼어 내기(연타) | J | A |
| 점프 (공중에서 J = 내려찍기) | K / Space | B |
| 무기 줍기 · 던지기 | L | 줍기/던지기 |
| 필살기 (업무 스킬) | I (게이지가 차면) | SP |
| 일시정지 | Esc / P | II |
| 조작법 숨기기·보기 | H | — |
| 판정 상자 보기 | ` / F2 | 주소 뒤에 `?debug` |

PC 게임 화면 오른쪽 아래에 조작법이 늘 떠 있다. PC에서 모바일 패드를 시험하려면 주소 뒤에 `?touch`를 붙인다.

## 캠퍼스 배경과 학교 로고

- 배경은 서울캠퍼스 실제 건물(본관, 사회과학관, 교수학습개발원, 인문과학관, 국제학사, 대운동장)을 학교 캠퍼스맵과 홍보 사진을 보고 코드로 그린 블록 도형이다(`src/scenes/background.ts`). 사진 파일은 레포에 넣지 않는다.
- 국제학사는 캠퍼스맵의 '학생회관 및 기숙사'(4번) 건물, 영문 GlobeeDorm이다. 인문관은 공식 이름 '인문과학관'으로 쓴다.
- 학교 로고는 새 학교 UI(남색 단색 심벌 + 굵은 고딕 HUFS)를 `public/hufs/`에 두고 쓴다(`src/hufs.ts`). 남색 심벌(`emblem.png`), 흰색 심벌(`emblem-mono.png`), 영문 약칭 HUFS(`hufs-type.png`), 국문 로고타입(`wordmark-ko.svg`). 흰색 파일은 게임에서 흰색·금색·남색을 입힌다. 모양과 비율은 바꾸지 않는다. 원본은 팀 드라이브 `2 협정\2 HUFS UI\추가_UI\`.

## 1인칭 시험판

`fps.html` + `src/fps/` (Three.js). 본관 앞 한 구역을 1인칭으로 걸으며 날아오는 "새벽 3시 메일"에 도장을 던져 세 차례 처리한다. 사람(학생·총장)은 나오지 않는다. 본편과 따로 돌고, 기록판에도 남기지 않는다.

- PC: WASD 이동, Shift 달리기, 마우스 시점(클릭하면 마우스가 잠김), 클릭 도장 던지기, Esc 일시정지
- 모바일: 왼쪽 화면 끌기 이동, 오른쪽 화면 끌기 시점, 빨간 "도장" 버튼
- 자동 시험: `fps.html?debug&timer` — `window.__fps`가 열리고 마우스 잠금 없이 시작할 수 있다.

## 기록판 서버

`apps-script/` 폴더의 `Code.gs`를 게임 전용 계정(staffsmash0)의 Google 시트에 붙여 웹 앱으로 배포했고, 주소가 `src/data/server.json`의 `recordsUrl`에 들어 있다. 설치 순서는 `apps-script/README.md`. 주소를 비우면 기록은 각 기기에만 저장된다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 확인
```

- 엔진: Phaser 3 + TypeScript, 빌드: Vite
- 밸런스: `src/data/enemies.json`(적), `weapons.json`(무기), `stage1~3.json`(구역·웨이브·상사·무기 배치)
- 주인공·스킬: `src/data/heroes.ts`, `skills.ts`
- `main` 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages로 배포한다.
- 자동 시험: `?debug&timer` — `window.__game`이 열리고, 창이 가려져도 게임 루프가 돈다.
- 프레지던트 캉은 총장실이 준 사진을 보고 블록형으로 옮긴 외형이다(`src/entities/rigs.ts`의 `createPresidentRig`, `createPresidentPortrait`). 원본 사진은 레포에 넣지 않는다(`.gitignore`의 `president.*`).
- 에셋 출처는 `assets/CREDITS.md`에 기록한다.
