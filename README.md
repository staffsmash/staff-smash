# Staff Smash: HUFS (비공식)

교직원과 학생이 서로의 입장을 웃으면서 겪어 보는 2D 벨트스크롤 액션 게임. 비공식 게임이며, 등장 인물과 부서는 가상이다.

플레이: https://staffsmash.github.io/staff-smash/

현재 단계: **M1 — 교직원 모드 1스테이지 "본관 사무실"**. 오후 4시 52분, 퇴근(17:00) 8분 전에 밀려드는 민원을 처리한다.

| 구역 | 내용 |
|---|---|
| 1. 민원 창구 | 새벽 3시 메일, 울리는 전화기 · 김보고 처장 |
| 2. 본관 복도 | 말풍선 "교수님이 된다고 했는데요", 중간보스 전화번호 잘못 입력한 학생 · 오검토 처장 |
| 3. 행정실 | 중간보스 서류 제출이 늦은 학생 · 두 처장 모두 |
| 4. 학생 상담실 | 보스 공지를 안 읽는 학생 — 안내문을 3번 붙여야 처리된다 |

학생 이름은 매 판 무작위로 바뀐다. 클리어하면 근무평정표(S~D)가 나온다.

## 조작

| 동작 | PC | 모바일 |
|---|---|---|
| 이동 (깊이축 포함) | 방향키 / WASD | 왼쪽 화면 드래그 |
| 대시 | 같은 방향 두 번 | 조이스틱 끝까지 밀기 |
| 처리(공격) | J | A |
| 점프 (공중에서 J = 내려찍기) | K / Space | B |
| 무기 줍기 · 던지기 | L | 줍기/던지기 |
| 필살기 "전체 공지 발송" | I (게이지가 차면) | SP |
| 일시정지 | Esc / P | II |
| 조작법 숨기기·보기 | H | — |
| 판정 상자 보기 | ` / F2 | 주소 뒤에 `?debug` |

PC 게임 화면 오른쪽 아래에 조작법이 늘 떠 있다. PC에서 모바일 패드를 시험하려면 주소 뒤에 `?touch`를 붙인다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 생성
npm run preview  # 빌드 결과 확인
```

- 엔진: Phaser 3 + TypeScript, 빌드: Vite
- 밸런스: `src/data/enemies.json`(적), `weapons.json`(무기), `stage1.json`(구역·웨이브·상사·무기 배치)
- `main` 브랜치에 올리면 GitHub Actions가 빌드해서 GitHub Pages로 배포한다.
- 자동 시험: `?debug&timer` — `window.__game`이 열리고, 창이 가려져도 게임 루프가 돈다.
- 에셋 출처는 `assets/CREDITS.md`에 기록한다.
