# 에셋 출처

에셋마다 출처, 작가, 라이선스, 수정 여부를 기록한다. 비상업 전용(NC)과 재배포 금지 에셋은 쓰지 않는다.

| 에셋 | 출처 | 작가 | 라이선스 | 수정 여부 |
|---|---|---|---|---|
| `public/hufs/emblem.png` 심벌 (남색) | 한국외국어대학교 새 UI (심벌 + HUFS 상하형) | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 심벌 부분만 잘라 320px로 줄임. 색·모양 그대로 |
| `public/hufs/emblem-mono.png` 심벌 (흰색) | 같은 파일 | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 같은 심벌을 흰색으로 바꿈 (게임에서 흰색·금색을 입힘) |
| `public/hufs/hufs-type.png` 영문 약칭 "HUFS" | 같은 파일 | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | HUFS 글자만 잘라 흰색으로 바꿈 |
| `public/hufs/wordmark-ko.svg` 국문 로고타입 | 한국외국어대학교 홈페이지 UI 파일 | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 색을 흰색으로 바꿈. 모양은 그대로 |
| `three` (1인칭 시험판 3D 엔진) | npm three 0.187 | three.js authors | MIT | 수정 없음 |

그 밖의 캐릭터·배경·효과는 모두 코드로 그린 도형이다. 배경 건물은 학교 캠퍼스맵(hufs.ac.kr HUFS MAP)과 홍보 캠퍼스 사진을 보고 그렸으며, 사진 파일은 쓰지 않는다. 프레지던트 캉은 총장실이 준 사진을 보고 블록형으로 옮겼고, 원본 사진은 레포에 넣지 않는다.
