# 에셋 출처

에셋마다 출처, 작가, 라이선스, 수정 여부를 기록한다. 비상업 전용(NC)과 재배포 금지 에셋은 쓰지 않는다.

| 에셋 | 출처 | 작가 | 라이선스 | 수정 여부 |
|---|---|---|---|---|
| `public/hufs/emblem.png` 컬러 심벌 | 한국외국어대학교 UI (심벌) | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 524px → 320px로 줄임 |
| `public/hufs/emblem-line.svg` 단색 심벌 | 한국외국어대학교 홈페이지 UI 파일 | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 색을 흰색으로 바꾸고 불필요한 id·clip-path를 지움. 모양은 그대로 |
| `public/hufs/hufs-type.png` 영문 약칭 "HUFS" | 한국외국어대학교 UI (약명 시그니처 가로형) | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 심벌을 뺀 HUFS 글자만 잘라 흰색으로 바꿈 |
| `public/hufs/wordmark-ko.svg` 국문 로고타입 | 한국외국어대학교 홈페이지 UI 파일 | 한국외국어대학교 | 학교 UI. 이 게임 안에서만 쓴다 | 색을 흰색으로 바꿈. 모양은 그대로 |

그 밖의 캐릭터·배경·효과는 모두 코드로 그린 도형이다. 배경 건물은 학교 캠퍼스맵(hufs.ac.kr HUFS MAP)과 홍보 캠퍼스 사진을 보고 그렸으며, 사진 파일은 쓰지 않는다.
